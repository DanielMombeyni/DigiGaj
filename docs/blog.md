# مجله دیجی‌گج

- فهرست: `https://digigadg.ir/blog/`
- مقاله: `/blog/<slug>/`
- سایت‌مپ مستقل: `https://digigadg.ir/sitemap-blog.xml`

مقالات با Django به صورت HTML کامل و بدون نیاز به اجرای جاوااسکریپت
نمایش داده می‌شوند. صفحه‌ها canonical، توضیح متا، Open Graph و داده ساختاریافته
دارند. آدرس بدون اسلش پایانی با 301 به آدرس اصلی منتقل می‌شود و مقاله ناموجود
404 است. فروشگاه لینک ورودی به بلاگ ندارد؛ بلاگ عمومی است و از طریق آدرس مستقیم،
سایت‌مپ یا موتور جست‌وجو قابل دسترسی است. از بلاگ به فروشگاه لینک وجود دارد.

سایت‌مپ محصولات و صفحه‌بندی آن تغییر نکرده‌اند. فقط سایت‌مپ جدید به فهرست
`/sitemap.xml` اضافه شده است؛ robots.txt همچنان به همین فهرست اشاره می‌کند.
سایت‌مپ جدید را می‌توان جداگانه نیز در Google Search Console ثبت کرد.
ثبت سایت‌مپ یا انتشار مقاله، ایندکس شدن و رتبه گوگل را تضمین نمی‌کند.

## نگهداری محتوا

محتوا در `backend/app/content/blog.py` نگهداری می‌شود و پنل مدیریت جداگانه ندارد.
برای مقاله جدید، یک مدخل با slug انگلیسی یکتا، عنوان، توضیح، دسته، تاریخ واقعی
انتشار و ویرایش و بخش‌های متن اضافه کنید. محتوای بخش‌ها متن ساده است و هنگام
نمایش escape می‌شود. فهرست و سایت‌مپ خودکار از همین محتوا ساخته می‌شوند.
تاریخ ویرایش را فقط پس از تغییر واقعی مقاله به‌روزرسانی کنید. پیش از انتشار،
صحت راهنما و ارتباط آن با کالاهای فروشگاه بررسی شود؛ از تکرار کلیدواژه و ادعای
تجربه یا آزمایش انجام‌نشده خودداری کنید.

## اجرا روی سرور

بعد از انتقال کد، از ریشه پروژه:

```bash
docker compose -f docker-compose.prod.yml up -d --build backend frontend
docker compose -f docker-compose.prod.yml exec -T proxy nginx -t
docker compose -f docker-compose.prod.yml restart proxy
curl -I https://digigadg.ir/blog/
curl -I https://digigadg.ir/sitemap-blog.xml
```

این قابلیت migration یا بازیابی مجدد بکاپ لازم ندارد. تنظیم مسیرها در Vite،
nginx فرانت‌اند و هر دو پیکربندی HTTP/HTTPS پروکسی اضافه شده است.
